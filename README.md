# RFHCStreamerTools

RFHC Streamer Tools is an all-in-one broadcast management suite for World of Warcraft streamers. Built specifically for content creators who need clean screen overlays, interactive audio triggers, and quick privacy tools, this lightweight addon gives you full control of your live production directly inside the game engine.

Key Features

AFK / "Be Right Back" Overlay: Automatically triggers a dark screen overlay with customizable title and subtext when your character goes AFK.

Interactive 3D Avatar Webcam: Floating, resizable 3D head camera window targeting your character. Includes an manual "Start Cam" startup control to ensure virtual cameras render reliably upon login.

On-Screen Soundboard Grid: Trigger classic World of Warcraft audio effects and voiced quote alerts directly from an organized on-screen grid or via /rfhcsound macros.

Built-in Stream Jukebox: Floating music player with integrated track navigation (Play, Stop, Skip, Random) and on-screen "Now Playing" popups.

Live Session Tracker Window: Real-time on-screen HUD tracking streaming duration, gold gained/lost, total deaths, dungeon completions, and PvP honor/HKs.

Anti-Harassment Mode: Auto-declines incoming trade requests, duel challenges, and random guild invites to keep your gameplay stream uninterrupted.

Slash Commands

/rfhcst or /rfhcstreamertools – Opens or closes the main settings control panel.

/rfhcsound <soundkey> – Plays a soundboard effect via macro (e.g., /rfhcsound murloc or /rfhcsound leeroy).
